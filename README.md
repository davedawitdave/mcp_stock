# **Crypto Market MCP Server**

This project exposes a set of cryptocurrency analysis and visualization tools through the **Model Context Protocol (MCP)**.
It features a clean, single-directory structure and provides two different transport methods—**HTTP** and **STDIO**—for integration with AI agents.

---

## **✨ Key Features**

* ✔ **HTTP MCP Server** — Tools exposed over a standard HTTP endpoint.
* ✔ **STDIO MCP Server** — Tools exposed over stdin/stdout for fast local integration.
* ✔ **Crypto Market Tools** — Price lookup, comparison, search, market overview, and chart visualization.
* ✔ **Compatible with FastMCP ≥ 2.13.2**
* ✔ **Web Visualization (Inspector UI)** via command line.

# **🚀 2. Running with Cursor**

This project can be run directly inside the **Cursor AI IDE**, which natively supports running MCP servers.

### **Step 1 — Open the project folder in Cursor**

1. Launch Cursor
2. Click **Open Folder**
3. Select the `mcp_stock/` directory

### **Step 2 — Start the MCP server inside Cursor**

Cursor automatically detects MCP servers if they expose a **main entry point**.

To run:

1. Open the file:

```
http_server.py
```

2. Press:

```
Ctrl + Shift + R
```

or use the **Run** button at the top of the editor.

Cursor will launch the HTTP MCP server and automatically register it as a Model Context Provider.

### **Expected Output in Cursor terminal**

```
[FastMCP] Server running on http://0.0.0.0:8000/mcp
Registered as MCP provider: Crypto Market Tools
```

You can now use the tools directly inside Cursor using:

```
@crypto <toolname>
```

For example:

```
@crypto get_crypto_price btc
```

### **Optional — Run with a custom port inside Cursor**

Inside the `Run` command settings, set:

```
python http_server.py --port 9000
```

## **🖥 MCP Inspector (Web UI)**

If you want a GUI to interact with your tools:

```bash
npx @modelcontextprotocol/inspector http://localhost:8000/mcp
```

This opens a browser where you can:

* View tool schemas
* Call MCP tools
* See raw JSON responses
* Preview charts generated by `visualize_crypto_comparison`

## **🔌 3. Running the STDIO MCP Server**

Ideal for high-performance local AI agents.

```bash
python stdio_server.py
```

There is **no web UI** for STDIO. It is meant for direct MCP client integration.

## **📦 4. Tools Provided by `tools_market.py`**

### ✔ `get_system_instruction()`

Returns system persona: **"cryptocurrency market analyst"**

### ✔ `get_crypto_price(ticker)`

Fetches the latest price for a cryptocurrency.

### ✔ `compare_cryptos(tickers)`

Compares multiple coins with structured metrics.

### ✔ `search_cryptocurrency(query)`

Fuzzy search for crypto names/tickers.

### ✔ `list_common_tickers()`

Returns popular assets like BTC, ETH, SOL.

### ✔ `get_market_overview()`

Provides overall market statistics and sentiment.

### ✔ `visualize_crypto_comparison(tickers)`

Generates a Matplotlib comparison chart.
Displayed automatically inside the **HTTP Inspector**.
